原本首頁是「置中、三段堆疊（Hero → 兩張角色卡 → 三張特色小卡）」。
2a 改成「**大字報 Hero 分欄** + **三欄特色列** + **深色使用須知帶**」，並新增頂欄與對外使用須知。路由與按鈕行為完全不變。

## 文案變更（重點）

改動集中在 `src/messages/zh-TW.ts` 的 `landing` 區塊；建議新增 key 而非覆蓋，方便回退。

**主標／副標（原本用 `app.name` + `landing.tagline`）**
- 主標：`把繳交登記交給小老師。`
- 副標：`你定的規則，小老師執行。老師做老師的事，管得更少、管得住。`
- （原 `tagline: '讓收回條和登記作業變得更簡單'` 不再顯示於 Hero，可保留給 PWA/meta）

**角色卡**（文字沿用現有 key，僅版面改變）
- `teacherTitle / teacherDesc / teacherCta` → 我是老師 / 建立班級、管理名單、查看報表 / 進入老師面板
- `helperTitle / helperDesc / helperCta` → 我是小老師 / 掃描老師的 QRCode 進入班級 / 掃描 QRCode 加入班級

**特色三欄（原 key 內容要換掉）**
| 原 key | 原文案 | 2a 新文案 | icon |
|---|---|---|---|
| `featureFastTitle/Desc` | 快速登記 / 一鍵勾選即時更新 | **免帳號即用** / 掃碼進入班級，無需註冊或密碼 | `lucide:qr-code` |
| `featureOfflineTitle/Desc` | 離線支援 / 無網路也能使用 | **離線可用 · 自動同步** / 網路不穩也能登記，連線後自動同步 | `lucide:refresh-cw` |
| `featureReportTitle/Desc` | 清晰報表 / 一目了然的統計 | **重點式提醒** / 僅在任務停擺或異常時提醒 | `lucide:bell-ring` |

原本三個 icon 是 `lucide:zap / lucide:wifi-off / lucide:bar-chart-2`，全部替換成上表。

**使用須知（全新，對外三點）**
1. **建班後立刻到設定複製「還原連結」並妥善保管**，換裝置貼上就能取回所有班級。
2. **還原連結像帳號密碼，只給自己用**；學生加入班級請用 QRCode，不要給還原連結。
3. **登記完，記得讓平板連上網完成同步**（顯示「已同步」）再交還。

## 樣式規範（沿用 ui-spec 既有 token，不新增顏色）

- 主色 primary `#2563eb`（按鈕實心用 `#3b82f6`）；強調黃 `#facc15`；底 amber `#fffbeb`；文字 `#0f172a` / 次要 `#64748b`；須知帶深色 `#0f172a`。
- **粗黑框**：所有卡片、按鈕、pill、頂欄分隔皆 `2px solid #000`（Hero 下緣 `3px`）。
- **偏移陰影**：卡片 `box-shadow: 5px 5px 0 #000`（行動版 4px），按鈕 `3px 3px 0 #000`。
- 字體 Noto Sans TC；主標 `font-weight:900`，`letter-spacing:-.03em`。
- 圓角：卡片 14px、按鈕/pill 8–999px、icon 方塊 12px。

## RWD 規則（斷點 640px）

- **桌機**：Hero 左右分欄（`1.08fr .92fr`）；特色三欄並排（欄間黑色直線）。
- **手機**：Hero 收成單欄（文字在上、兩張角色卡在下）；主標 50px → 34px；特色三欄改直排，分隔線由直線改橫線；容器左右黑框拿掉。
- 參考 `首頁-2a.html` 的 `@media (max-width:640px)` 區塊，斷點與數值可直接對應 Tailwind（`sm:` = 640px）。

## 實作提示（Next.js + Tailwind）

- 維持 `page.tsx` 的 `'use client'`、`Link`、`Icon`、`Button`、`useMessages`。
- 角色卡按鈕沿用 `<Button variant="primary|secondary">` 包 `<Link>`；`/teacher`、`/join` 路由不變。
- 頂欄、Hero 色塊、須知帶是新增的靜態區塊，直接以 Tailwind class 刻即可（對照 `首頁-2a.html` 的 inline 樣式換算）。
- icon 用專案的 `<Icon name="lucide:..." />` 包裝，名稱如上表。
- 須知內容建議放進 `messages.landing.notices` 陣列，避免寫死在 JSX。
